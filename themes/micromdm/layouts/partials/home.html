Nano is the new Micro

NanoMDM (and the Nano-suite of projects) is the new direction we’re currently focused on. The MicroMDM "v1" project has been in maintenance mode for over a year and is now deprecated.

MicroMDM organization projects

  • NanoMDM

    A minimalist Apple MDM server and library heavily inspired by MicroMDM. The core of the organization's new direction.

    NanoMDM on GitHub

  • NanoDEP

    Tools and a Go library for communicating with Apple's Device Enrollment Program (DEP) API servers.

    NanoDEP on GitHub

  • NanoHUB

    Unifies NanoMDM, NanoCMD, and KMFDDM into a single MDM server, with migration capabilities. Includes a reference server.

    NanoHUB on GitHub

  • NanoAXM

    Tools and Go libraries for communicating with the Apple School and Business Manager API.

    NanoAXM on GitHub

  • KMFDDM

    Sister project: an Apple Declarative Device Management (DDM) server that works together with NanoMDM. Note: experimental.

    KMFDDM on GitHub
